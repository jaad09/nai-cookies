# ناي بيكري | Nai Bakery
طوّرتُ ناي بيكري باستخدام Flutter وFirebase. يضم التطبيق واجهة للعميل لتصفّح المخبوزات وإرسال الطلبات، ولوحة تحكم لصاحب المخبز لإضافة المنتجات وحذفها وتعديل أسعارها وصورها وتحديث صور البانرات.

## واجهة العميل
- تصفّح المخبوزات والاطّلاع على صور المنتجات وتفاصيلها.
- إضافة المنتجات إلى السلة ومراجعة الطلب قبل إرساله.
- إنشاء حساب وتسجيل الدخول بالبريد الإلكتروني وكلمة المرور.

## لوحة تحكم المخبز
- إضافة منتجات جديدة وحذف المنتجات من المتجر.
- تعديل أسعار المنتجات وتغيير صورها.
- تغيير صور البانرات المعروضة في التطبيق
- متابعة الطلبيات.

## التقنيات المستخدمة
- Flutter وDart لبناء واجهة العميل ولوحة التحكم.
- Firebase Authentication لإدارة حسابات العملاء.
- Cloud Firestore لحفظ الطلبات.
